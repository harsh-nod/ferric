# Ferric finite kernel catalog foundation

This crate maps every operation in the 22 exact target/draft B3 sequential
plans to one of seven finite kernel families. Each family is pinned to the
repository, pull request, commit, tree, and primary source path of the reviewed
fe2o3 K1-K7 fixture/model foundation. The record also binds the future fe2o3
source closure, compiler, target, kernel proof/ABI, runtime contract/ABI, and
TCB identities required by the offline build.

The K1-K7 pull requests are unmerged historical structural foundations whose
pinned heads may be stale; in particular, a CPU fixture/model is not a
production GPU kernel. The verified operation handoff does not consume this
roster as authority. Some graph operations require extensions beyond the exact
upstream fixture envelope; the catalog marks those bindings
`RequiredExtension`. No binding is proof evidence or an executable candidate.
This crate contains no kernel source, compiler
integration, object, HSACO, device allocation, queue, load, dispatch, launch,
completion, hardware observation, performance result, or qualification
receipt. It does not close any M1 roadmap or property obligation.
