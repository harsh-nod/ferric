Genuine tensor comparisons require identical entire input histories. After the
first differing input, subsequent genuine rows remain incomparable even if
later tokens coincide. A differing final output alone does not invalidate the
four already-identical input histories.

passes consume the native four-token input history. These are labeled
`native_input_conditional`, never genuine autoregression. Only tokens are
borrowed, never native tensors, KV or logits. They permit 152 conditional tensor
comparisons, but do not establish native token recurrence against the genuine
framework. The unchanged retained BF16 diagnostic formulas are used without
tolerances, thresholds or acceptance decisions.
