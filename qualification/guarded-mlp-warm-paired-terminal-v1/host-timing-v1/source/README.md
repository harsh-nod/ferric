# One-Pair Segment Host Diagnostic

Source proposal only. No actual control/candidate outcomes are embedded, and
no fixture test or renderer execution is claimed by its author.

The single stdlib renderer consumes the exported or retained native pair capsule and both
observed terminal SHAs. It hashes every original manifest body, then invokes
the exact pinned pure retention verifier (`9fc9b80e...`) from that capsule.
Only two successful, fully revalidated cases permit rendering. The original
validator recomputes the four-by-36 host intervals from each original binary
control body; those results must equal the original terminal observations.
No controller, model, subprocess, GPU, or network API is invoked.

```text
python3 -B -m unittest -v test_render
python3 -B render.py RETAINED_NATIVE_PAIR CONTROL_SHA CANDIDATE_SHA FRESH_OUTPUT
```

Root owns the bounded test invocation and subsequent rendering. The seven
fixture methods cover exact integer aggregation, first-use/warm membership,
unsigned integer and extent refusals, policy/cadence/authority refusals,
same-ELF/payload/history/timer joins, zero denominators and decimal ties,
lossless CSV values, and fixed structured SVG layout. They do not exercise or
qualify GPU execution. No new standalone qualification harness is added.

On the native host, root may stage the already hash-checked exported archive
into a fresh ordinary directory and render there; a local `retention.json`
is optional, not invented. The exact tree is manifest plus its original
bodies, optionally plus that existing retention receipt. No original native
source or case directory is modified.

Outputs are `layers.csv` (288 observations), `summary.csv` (four positions and
two first-use/warm aggregate rows), `summary.md`, `segments.svg`, and
`comparison.json`. A separate `complete.json` records source/input posthashes
and output pins. CSV and JSON retain exact integer nanoseconds; displayed
milliseconds and relative change use decimal round-to-nearest, ties-to-even.
Relative change means 100 times (candidate minus control) divided by control;
zero denominators are unavailable, not infinity or an invented improvement.

The SVG contains four fixed panels, one per position, with the same zero-based
scale and both modes plotted across all 36 layers. Positions 0/1 are first-use
legacy terminal paths in both cases. Positions 2/3 use genuine retired-arena
reuse, with paired terminal dispatch only in the candidate. An aggregate row
is a sum of observed disjoint coordinator segments, not another run/sample.

The runtime's `coordinate_with_terminal_policy` brackets preflight through
owner consumption, reservations, publication, polling, retirement and terminal
checks. Its `segment_host_ns` excludes earlier setup/allocation, prefix work,
later hidden reads and the rest of the forward. No inclusive timer is added to
or subtracted from these intervals. Runtime source custody remains the
separately retained actual CPU qualification.

This is one serial control/candidate pair using the same qualified ELF pair.
The four forwards per run are correlated. It is not a controlled repeated
benchmark, causal attribution, GPU timing, throughput or end-to-end speedup.
Payload/history equality is a required implementation-parity gate, not an
independent accuracy reference or numerical acceptance threshold.

Rendering uses a 60-second wall deadline, 50 CPU seconds, 256 MiB address-space
limit, 64 MiB total input, at most 256 input files, 16 MiB per input, and 1 MiB
per output. The capsule and its metadata are read-only. Outputs are fresh and
exclusive; all original pins and the closed input roster are rechecked before
publication. Failure is not rewritten into a successful report.
