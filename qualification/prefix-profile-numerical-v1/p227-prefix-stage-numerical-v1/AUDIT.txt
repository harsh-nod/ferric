Existing fixed conditional gates
--------------------------------
P/p227-prefix-numerical-sidecar-v1/attention-policy.json: position0 exact;
otherwise ordered BF16 distance <=1 OR absolute error <=5e-5 times causal
per-KV-head max|V|. This is unchanged P214 policy, not a whole-model tolerance.

Its output_reference.py:45-82 derives the P215 O K2048 bound from gamma39,
FP64 gamma2048, outward sum|w*x| and4159 half-subnormal allowances. P218
reference.py:109-246 and policy.json fix K4096/depth71/8255 and
K6144/depth103/12351, dual-BF16 norm intervals with <=1-F32-ULP sqrt prerequisite
and a32-candidate refusal cap. SwiGLU allows at most one ordered BF16 step versus
independent stable FP64 SiLU, conditional on accepted actual gate/up; residual
uses the frozen exact integer oracle. These are operator checks conditional on
actual preceding arrays, not independent own-KV model propagation.

The prior prefix sidecar compare_numerical.py:205-220 consumes only captured
query/causalKV/attention/O. Captured normalized and packed QKV stages were not
numerically checked there. This proposal fills that specific CPU-only gap and
adds source-counted serial128 headnorm plus staged RoPE/current V append checks.
It does not silently extend the old attention/O result.

Source-derived obligations and remaining gaps
---------------------------------------------
inputs/wave_numerics_v1.rs:4-56 has64 products/additions per lane and six Wave64
XOR reduction stages at K4096. Reusing the unchanged P218 gamma71 class is
justified for exactly this shape and separate arithmetic, not arbitrary GEMM.
inputs/finite_qkv_attention_output_tiles_v6.rs:37-103 retains the same input
norm/epsilon/dual narrowing and delegates the same head post-processing.

inputs/head_rope_numerics_v3.rs:5-31 instead serially sums128 squares. It cannot
inherit the wave-norm gamma71. The new preregistered bound counts a maximum
129 rounding depth and256 half-subnormal operations, starting from an exact
integer BF16 square sum. It retains the existing <=1-F32-ULP sqrt/RNE divide
prerequisites and fixed32-candidate cap. Lines34-129 require two BF16 norm
boundaries, split-half pairs and separate FP32 multiply/add stages for RoPE.
This checker conditions on authenticated supplied FP32 rotary words; it does
not prove their trigonometric generation error. Candidate sets overapproximate
shared-inverse correlation and are explicitly only necessary consistency tests.

Open: artifact-linked sqrt/divide and OCML contracts over their admitted input
domain; mathematically justified error for online attention over propagated
query/key/value uncertainty; retained final-norm operation/reduction contract;
MFMA head error/rounding contract (do not reuse gamma71/39); propagation through
both residual fences and independent all36 own-KV trajectories. BF16 boundaries
are discontinuous and require cell/interval reasoning, not accumulated RMSE.

The all36 payload exposes36 hidden outputs, final norm and logits, not each
layer's normalized/QKV/headnorm/gate/up/activation/rank-partial arrays. Therefore
the existing152 tensor rows cannot retrospectively discharge all conditional
operator premises. More layer-stage capture or independently propagated bounds
is needed; no generic evidence framework is needed for that arithmetic work.

Minimum held-out plan to preregister, not an acceptance claim
-----------------------------------------------------------
1. Fix the TP2 operator catalog, admitted numerical domains, exact source/object
   prerequisites, outward bounds and refusal behavior before evaluating new
   data. Run this new checker first on synthetic source-derived discriminators;
   only afterward root may evaluate the retained standalone captures. A bound
   refusal is retained, never repaired by increasing a tolerance after exposure.
2. Freeze fresh prompt tokens and deterministic stress seeds before candidate
   execution. Proposed new positions1/63/64/127/128/1023/1024/2302 exercise page,
   reduction and context boundaries outside the old six cases. Use actual layer
   weights from layers0/17/35,both ranks, then all36 boundary outputs. Include
   cancellation, BF16 midpoints, signed zeros, gradual underflow and near-overflow
   admitted inputs. These cases/seeds are proposed, not yet frozen or executed.
3. Run a genuinely held-out authenticated2048-token prompt plus256 own-output
   decode, with two fresh independent ownKV reference passes. Extend reference
   capture to the new Long257 full-payload positions0 and2047..2302 (38 tensors
   each), not just tokens/logits. Keep fixed-input teacher forcing separate from
   target-only AR; after divergence do not claim same-input tensor comparison.
4. Accept tensors only under independently justified operator/propagation
   envelopes or an explicitly accepted upstream numerical contract. Where a
   logit interval gives lower(winner)>all competing uppers, record a token
   certificate; otherwise report uncertified, not an invented global tolerance.
   Passing finite held-out cases remains bounded validation, not a proof over
   every model input. No aggregate threshold is supplied here.
