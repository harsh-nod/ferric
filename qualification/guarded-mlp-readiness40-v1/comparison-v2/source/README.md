## Primary Invocation

After peer review and actual reference archive/terminal binding, stage the eight
Python source bodies unchanged, then run in a fresh output namespace:

```sh
python3 -I -B run_bound.py --native-archive ACTUAL_NATIVE_ARCHIVE --checker-archive ACTUAL_CHECKER_ARCHIVE --reference-archive ACTUAL_REFERENCE_ARCHIVE --output FRESH_OUTPUT
```

All paths must be absolute, canonical, ordinary files. The two future pins are
`REFERENCE_ARCHIVE` and `REFERENCE_TERMINAL`; no code/function change is needed
when binding them. Keep the unbound source and exact reversal of the two literal
changes. The same seven sibling modules are required next to the bound runner.

Bounds are 180 seconds, 1 GiB address space, CPUs 8/9, nice 10, GPU-hidden
environment, 128 MiB total readset and 8 MiB per output body. Archive members are
ordinary unique USTAR paths with exact fixed successful censuses and bounded
expanded bytes. The adapter uses isolated Python and no bytecode. Every consumed
archive/helper/controller is rehashed after comparison, and a catchable whole
deadline remains active through postchecks and exclusive terminal publication.
Failures preserve a separate `failed.json` when bounded cleanup permits; they
cannot publish accepted success. Original evidence is never edited.
