# Runtime And Worker Integration

The 22 actual tested runtime and worker postimages are integrated: ten runtime
files and twelve worker files. The default and diagnostic MI350 builds used
identical project sources and passed independently. These are their final
formatted source bodies, not untested proposal copies.

The [complete source postcheck](postcheck.json) authenticates all 827 canonical
runtime bodies and 1,299 canonical Ferric bodies. It preserves both workspace
manifests and lockfiles and all four proposed parent preimages. Only the listed
22 source changes are admitted by this integration. The separate parent
qualification is still pending.

The postcheck also compares all 1,065 project source bodies in the two original
CPU capsules. Helper sources differ by mode and are not included in that
project-source equality claim. Original failed attempts remain retained.

This is a source integration checkpoint, not native GPU execution, numerical
acceptance, a timing breakdown or a full-request throughput result.
